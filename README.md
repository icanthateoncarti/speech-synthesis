# speech-synthesis

- **Statut** : actif — outil « La Machine »
- **But** : outil de synthèse vocale française dans le navigateur — voix Jessica ou Tom, vitesse réglable, écoute en direct, téléchargement MP3, import PDF et PPTX, lecture des textes anglais avec des voix anglaises.
- **Site** : https://speechsynthe.si (GitHub Pages, branche `main`)
- **Publication** : mise à jour du 2026-10-28 — bibliothèque locale, reprise des passages audio, OCR et aperçu des PDF, partage chiffré à expiration. Détails : [`docs/2026-10-28-library-pdf-sharing.md`](docs/2026-10-28-library-pdf-sharing.md).
- **Dépendances** : ES modules JavaScript, Web Audio, vits-web, onnxruntime-web, Paper shaders, lamejs, PDF.js, Tesseract.js 6.0.1, Cloudflare Worker + Durable Object SQLite pour le partage, tests Node et Puppeteer.
- **Données** : lecture, extraction PDF et OCR sur l’appareil. La création volontaire d’un lien envoie uniquement une copie chiffrée du texte et des réglages, avec expiration à 7 jours. La bibliothèque reste dans le navigateur.
- **Code vocal** : [`src/vendor/vits-web/PATCHES.md`](src/vendor/vits-web/PATCHES.md). Jessica (UPMC) est sous CC BY-SA 4.0 ; Tom est sous AGPLv3. Le dépôt reste public.
- **Tests** : `npm test` ; `npm run test:e2e` (Google Chrome installé et connexion Internet pour les bibliothèques et modèles).
- **Navigation + glisser-déposer** : disponibles — barre de lecture (±30 s, position, chapitres), panneau COMMANDES (sauts par phrases/secondes/chapitres, commande écrite, micro local facultatif), PARLE = pause/reprise, import PDF par glisser-déposer. Commandes : `docs/voice-commands.md`. Spec : `docs/superpowers/specs/2026-10-24-la-machine-design.md`.
- **Textes** : réécriture du 2026-10-26 à partir des principes de copywriting des notes Obsidian (bénéfice concret, vocabulaire utilisateur, objections, une idée par phrase) ; FAQ courte, deux voix par langue, limites d’import explicites. Positionnement issu du message à la classe : réviser un cours sans résumé automatique, lecture en anglais et MP3 à écouter en déplacement ; retour de bugs via GitHub.
- **Interface** : pupitre rééquilibré, trois rangées sur mobile, nom du document dans l’écran, bouton de voix au glisser (souris/doigt), commandes avancées accessibles au clavier et outils PDF de 44 px minimum.
- **Nettoyage** : après import PDF ou PPTX, NETTOYER propose les en-têtes/pieds de page répétés avec aperçu et cases à cocher. Les chapitres numérotés et les cellules de tableaux restent protégés ; restauration possible sans perdre la sélection PAGES.
- **Export MP3** : encodage dans un worker dédié, annulable, mêmes octets/qualité qu’avant ; progression séparée pour la préparation audio et l’encodage. La synthèse d’un long document dépend toujours des performances de l’appareil.
- **Préparation audio** : moteur initialisé dès la saisie/import, réutilisation des passages après correction/nettoyage/sélection. Cache RAM borné à 8 Mio / 128 passages, vidé par EFFACE ou nouvel import. Mesures et limites : `docs/document-import.md` ; `node scripts/benchmark-tts.mjs`.
- **Passages PDF** : la touche PAGES affiche le document et permet de surligner les passages à lire ou à sauter, puis de revenir à la radio avec la sélection ; extraction et surlignages restent locaux.
- **Symboles dits à voix haute** : `src/spoken.js` réécrit le texte envoyé à la voix (« entre parenthèses », « entre guillemets », « flèche vers la droite », & → et, 2025/2026, 1er/1ère) ; l'écran garde le texte d'origine. Les tableaux PDF balisés sont lus par lignes, avec rappel des en-têtes de colonnes ; extraction habituelle conservée pour les tableaux non balisés ou ambigus.
- **Anglais et PPTX** : langue détectée sur le texte (`detectLanguage`, `src/text.js`) → voix anglaises Kristin (domaine public) / Joe (CC0) aux positions Jessica / Tom ; import `.pptx` local sans bibliothèque (`src/pptx.js`, ZIP + DecompressionStream), une diapo = un chapitre, titres de diapo avec pause.
- **Publier** : `npm run build` (empreinte de version dans `index.html` contre le cache de 10 min de GitHub Pages, pages par usage régénérées, sitemap), tests, commit, puis `git push origin feat/la-machine:main`. Des tests échouent si l'empreinte ou les pages ne sont pas à jour.
- **Découverte IA** : cinq versions Markdown, `llms.txt`, `llms-full.txt`, `ai.txt`, catalogue JSON et règles de robots. Sources et limites GitHub Pages : `docs/ai-discovery.md`.
- **Pages par usage** : `/pdf-en-audio/`, `/text-to-speech/`, `/voix-off/`, `/message-repondeur/`, générées depuis `index.html` par `scripts/build-pages.mjs` ; textes dans `scripts/pages.mjs` (`HOME` pour l’accueil, `PAGES` pour les usages ; choisies sur Google Trends FR, 2026-10-25). Ne pas éditer les `*/index.html` à la main.
- **Indexation** : IndexNow (Bing, ChatGPT Search, Copilot, DuckDuckGo) avec la clé `904e353b535ac91e0d802ce54522f5c6.txt` à la racine, ne pas la supprimer ; après une publication qui change des pages, renvoyer leurs URL à `https://api.indexnow.org/indexnow` (soumis le 2026-10-25 : 202). Google : Search Console, propriété préfixe d'URL vérifiée par le fichier `google47078ed0a8b5dade.html` à la racine (ne pas le supprimer, sinon la propriété est perdue).
- **Sécurité** : CSP en balise meta générée par `npm run build` (`contentSecurityPolicy` dans `scripts/stamp-version.mjs`) ; un nouveau CDN ou un script en ligne doit y être autorisé, sinon il est bloqué (test `tests/e2e/csp.test.mjs`). Voix figées et vérifiées par SHA-256 (`src/vendor/vits-web/PATCHES.md`, point 4). Budgets d'import : `src/limits.js`. Rapport d'audit : `docs/security/`, hors dépôt.
